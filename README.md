# Aksara Jawa Recognizer

Handwritten Aksara Jawa (Javanese script) character recognition web app. Powered by a **MobileNetV2** backbone pretrained on Chinese handwritten characters (HCCR) and fine-tuned on 20 Aksara Jawa characters.

Runs **100% client-side** — ONNX models execute in the browser via ONNX Runtime Web. No backend required, deploy anywhere (Vercel, Netlify, static hosts).

## Features

- ✍️ Interactive canvas — draw a character, get instant prediction
- 🔢 All model versions selectable: **V1, V1.1, V2, V2.1, V3, V3.1, V3.2**
- 📊 Top-5 predictions with confidence bars
- 📖 Reference chart of all 20 recognized characters (with Javanese script glyphs)
- ⚡ Lazy model loading — only the selected model is fetched
- 🌙 Dark mode support

## Getting started

### 1. Install dependencies

```bash
npm install
```

This also copies the ONNX Runtime WASM binaries into `public/ort/` (via the `postinstall` script).

### 2. Export the models to ONNX

You need **Python 3.9+** with PyTorch installed:

```bash
pip install torch torchvision onnx
npm run export:models
```

This loads each `.pt` checkpoint from `../aksara-jawa/models/` and writes the 7 ONNX models to `public/models/` (v1.onnx … v3.2.onnx).

> The `pretrained_chinese.pt` base checkpoint is required to reconstruct the MobileNetV2 architecture. All fine-tuned variants share this backbone.

### 3. Run it

```bash
npm run dev       # development
npm run build     # production build
npm start         # serve production build
```

## How it works

1. You draw a character on the canvas (`<canvas>` at 400×400)
2. The drawing is preprocessed in-browser to match the training pipeline:
   - Grayscale conversion
   - Foreground bounding-box crop (pixels < 220)
   - Long edge scaled to 56 px, aspect ratio preserved (bilinear)
   - Center-pasted onto a 64×64 white canvas
   - Normalized to [-1, 1]
3. The 64×64 grayscale tensor feeds the ONNX MobileNetV2 model
4. Softmax over 20 logits → top-5 predictions with confidence

## Model info

| Version | Checkpoint | Unfrozen layers |
|---------|-----------|-----------------|
| V1      | `chinese_finetune_v1.pt` | classifier only |
| V1.1    | `chinese_finetune_v1.1.pt` | classifier only (refined) |
| V2      | `chinese_finetune_layer10_v2.pt` | layers 10–18 |
| V2.1    | `chinese_finetune_layer10_v2.1.pt` | layers 10–18 (refined) |
| V3      | `chinese_finetune_layer14_v3.pt` | layers 14–18 |
| V3.1    | `chinese_finetune_layer14_v3.1.pt` | layers 14–18 (refined) |
| V3.2    | `chinese_finetune_layer14_v3.2.pt` | layers 14–18 (**best**) |

- [PyTorch](https://pytorch.org) — model training & ONNX export
